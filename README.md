# What is NyxAI?
NyxAI is a local-first AI platform that helps me build software, create gaming content, automate repetitive work, and continuously improve own data.

## Why does it exists?
It exists because I had a simple idea, idea to generate replies for my audience comments and I have a powerful enough specs to run local models. 
It exists to help me write code, create softwares, analyse my social media, draft comments and responses, generate titles and descriptions, create images and tumbnails and a lot more! 

## Were do I start?
To be very honest, I don't know. I would like to start with setting up different capabilities (rather than models) like software engineer, architect, debugger, creator, analyst, researcher, community manager, automation etc. and then go ahead building each one of them, as I move forward, create projects, learn about the concepts and deepen my knowledge about llm and agents, and everything else there is to know and learn.
